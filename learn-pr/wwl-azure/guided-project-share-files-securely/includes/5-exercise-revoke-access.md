This guided project consists of the following exercises:

- Exercise 1: Create storage and upload file
- Exercise 2: Create an access policy and generate a SAS link
- Exercise 3: Test partner access behavior
- **Exercise 4: Revoke partner access**
- Exercise 5: Configure lifecycle management
- Clean up resources

In this exercise, you revoke partner access by modifying the stored access policy. This demonstrates how stored access policies let you invalidate a SAS token without changing the storage account keys.

The exercise consists of the following tasks:

- Modify the stored access policy to revoke access
- Verify the SAS link no longer works

Launch the exercise and follow the instructions. When you're done, be sure to return to this page so you can continue learning.

> [!NOTE]
> To complete this lab you will need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).
