In this exercise, enable Microsoft Defender for Servers Plan 2 on an Azure subscription and review its features. This is one example of a Defender for Cloud workload protection plan, not a deployment of every Defender plan.

> [!IMPORTANT]
> Use an Azure commercial training subscription that you're authorized to change. Before launching the lab, review the permission and pricing guidance in the preceding unit. Enabling a subscription-level plan can affect existing eligible resources, not just resources used for training.

To change the subscription's Defender plans, use an account with Security Admin, Contributor, or Owner at subscription scope. Enabling every capability can require Owner permissions and additional component-specific prerequisites.

Record the existing Servers plan, selected tier, and settings before making changes. If you already followed the preceding unit's walkthrough, use the configuration recorded before those changes and avoid repeating them. Review remaining trial eligibility and current pricing. A paid trial can end when a plan's usage limit is reached, before 30 days have elapsed. Azure resource charges aren't waived by a Defender plan trial.

The linked lab enables Servers Plan 2 and reviews its features. You don't need to create a VM just to save the plan configuration. To verify workload protection, you'll also need an authorized, supported test machine in the subscription.
