Defender for Cloud incorporates security early in the software development process through DevSecOps. It assesses code-management environments and pipelines and correlates findings with cloud-resource context.

Applications require controls at the code, infrastructure, and runtime levels. Defender for DevOps connects supported GitHub, Azure DevOps, and GitLab environments to Defender for Cloud.

| Capability | Purpose | Defender plan |
| --- | --- | --- |
| [Code-pipeline insights](/azure/defender-for-cloud/defender-for-devops-introduction) | Identify infrastructure-as-code misconfigurations, exposed secrets, and other DevOps findings, and correlate them with cloud context. | Foundational CSPM and Defender CSPM |
| Code-to-cloud contextualization | Relate code owners and repository findings to affected cloud resources so teams can prioritize remediation. | Defender CSPM |

DevSecOps is one part of the broader CNAPP. The remaining units focus on protecting running server workloads rather than configuring repository connectors.
