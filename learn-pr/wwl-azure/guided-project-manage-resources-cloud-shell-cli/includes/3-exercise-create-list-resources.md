This guided project consists of the following exercises:

- Exercise 1: Open Cloud Shell and explore the environment
- **Exercise 2: Create and list resources with CLI commands**
- Exercise 3: Tag, query, and clean up resources
- Clean up resources

In this exercise, you create a resource group and two storage accounts entirely from the command line, then use listing commands to verify what you built. This demonstrates how the CLI lets you accomplish in a few commands what takes many portal clicks.

The exercise consists of the following tasks:

- Create a resource group using CLI commands
- Create two storage accounts using CLI commands
- List and verify resources with CLI commands

Launch the exercise and follow the instructions. When you're done, be sure to return to this page so you can continue learning.

> [!NOTE]
> To complete this lab you will need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).
