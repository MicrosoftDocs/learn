This guided project consists of the following exercises:

- Exercise 1: Create an action group
- Exercise 2: Create a Service Health alert
- **Exercise 3: Create an Activity Log alert**
- Clean up resources

In this exercise, you create an Activity Log alert that fires when any resource is deleted in your resource group, then review both alert rules to confirm they're configured correctly. This gives your operations team real-time awareness of infrastructure changes.

The exercise consists of the following tasks:

- Create an Activity Log alert for resource deletion
- Review all configured alert rules

Launch the exercise and follow the instructions. When you're done, be sure to return to this page so you can continue learning.

> [!NOTE]
> To complete this lab you will need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).
