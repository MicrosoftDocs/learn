This guided project consists of the following exercises:

- **Exercise 1: Create resources and apply tags**
- Exercise 2: Apply resource locks
- Exercise 3: Test lock enforcement
- Clean up resources

In this exercise, you create a resource group with two storage accounts and apply organizational tags to each one. You then use tag-based filtering to see how tags help you find and organize resources across a growing environment.

The exercise consists of the following tasks:

- Create a resource group and storage accounts
- Apply tags to resources
- Filter resources by tag

Launch the exercise and follow the instructions. When you're done, be sure to return to this page so you can continue learning.

> [!NOTE]
> To complete this lab you will need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).
