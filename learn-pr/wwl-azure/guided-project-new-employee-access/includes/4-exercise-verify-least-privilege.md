This guided project consists of the following exercises:

- Exercise 1: Create user and group
- Exercise 2: Assign RBAC role at scope
- **Exercise 3: Verify least-privilege model**
- Clean up resources

In this exercise, you validate the access model you built by checking permissions with IAM, reviewing the audit trail, and signing in as the new user to experience the Reader role firsthand.

The exercise consists of the following tasks:

- Review role assignments in IAM
- Review the audit trail
- Sign in as the new user and verify Reader access

Launch the exercise and follow the instructions. When you're done, be sure to return to this page so you can continue learning.
