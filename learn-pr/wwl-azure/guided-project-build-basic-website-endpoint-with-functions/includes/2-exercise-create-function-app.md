This guided project consists of the following exercises:

- **Exercise 1: Create the function app**
- Exercise 2: Create an HTTP-trigger function
- Exercise 3: Test endpoint and review logs
- Clean up resources

In this exercise, you create a resource group and deploy a Function App using the serverless Flex Consumption plan. When you're done, you have a running Function App ready to host your first function.

The exercise consists of the following tasks:

- Create a resource group
- Create a Function App

Launch the exercise and follow the instructions. When you're done, be sure to return to this page so you can continue learning.

> [!NOTE]
> To complete this lab you will need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).
