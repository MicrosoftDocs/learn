This guided project consists of the following exercises:

- Exercise 1: Apply cost-tracking tags
- **Exercise 2: Create budget and alerts**
- Exercise 3: Assign and test an Azure Policy
- Clean up resources

In this exercise, you create a budget with alert thresholds that notify you before spending exceeds your target. Budget alerts give you early warning so you can investigate and adjust before costs get out of control.

The exercise consists of the following tasks:

- Create a budget for a resource group
- Configure alert thresholds and notification recipients

Launch the exercise and follow the instructions. When you're done, be sure to return to this page so you can continue learning.

> [!NOTE]
> To complete this lab you will need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).
