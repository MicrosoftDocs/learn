Azure Data Lake Storage isn't a separate service or account type. Instead, it's a set of capabilities built on top of Azure Blob Storage that you enable by selecting the *hierarchical namespace* setting when you create a storage account. This design means you get analytics features such as compatibility with big data analytics frameworks like Apache Spark, a hierarchical directory structure, a security model that supports Azure role-based access control (RBAC) and POSIX-style access control lists (ACLs), and scalability for large amounts of data, at Azure Blob Storage price levels.
