Microsoft Adaptive Accessories and the Surface Adaptive Kit help create more inclusive device experiences by giving users flexible ways to interact with their Surface devices and Windows PCs. In this module, you'll explore how adaptive mice, hubs, buttons, and tactile labels can help address common mobility, reach, strength, and identification barriers in the workplace. You'll also review practical setup steps and real-world use cases that show how these tools can support productivity, independence, and personalized workflows for employees with different access needs.

## Learning objectives

By the end of this module, you'll be able to:

- Describe how Microsoft Adaptive Accessories and the Surface Adaptive Kit can help address common device interaction barriers.
- Identify the purpose of the Microsoft Adaptive Mouse, Adaptive Hub, Adaptive Buttons, and Surface Adaptive Kit components.
- Connect and configure adaptive accessories to support personalized input and productivity workflows.
- Apply use case scenarios to determine which adaptive tools can support different workplace accessibility needs.
