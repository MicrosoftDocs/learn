**AI Dev Gallery (Preview)** helps learners explore Foundry on Windows by running local AI experiences directly on Copilot+ PCs. In this module, learners install and use **AI Dev Gallery**, explore **Samples**, **Models**, and **Windows AI APIs**, and showcase demos such as text generation and image classification. These experiences demonstrate how on-device AI and the Neural Processing Unit (NPU) can improve responsiveness, reduce cloud dependency, and help in achieving Microsoft’s goal to deliver **unmetered intelligence** to every desk and every home.

In this module, you learned how to:

- Access and install **AI Dev Gallery (Preview)** from the Microsoft Store.
- Explain how **Foundry on Windows** enables local AI workloads on Copilot+ PCs.
- Explore **AI Dev Gallery (Preview)** experiences, including **Samples**, **Models**, and **Windows AI APIs**.
- Run sample scenarios that demonstrate text generation and image classification with an NPU specific model.

You also explored key concepts and scenarios such as:

- The role of local AI in reducing cloud reliance and enabling responsive, on-device experiences.
- How **AI Dev Gallery (Preview)** helps users discover models, test samples, and understand AI APIs for Windows apps.
- How Copilot+ PCs use the NPU to run supported AI workloads efficiently on the device.
- Real-world applications such as retail store compliance with image classification and sales proposal support with text generation.

At this point, you should have a clear understanding of how **AI Dev Gallery (Preview)** can be used to demonstrate the building blocks of local AI applications, from practical samples to business-ready scenarios. These experiences show how **Foundry on Windows** and Copilot+ PCs can bring intelligent, responsive, and scalable AI capabilities directly to the endpoint.
