This module explores how Surface devices and Microsoft 365 help business users work more efficiently across everyday productivity scenarios. You'll learn how Surface hardware features—such as touch, pen input, Studio Microphones, PixelSense displays, and voice capabilities—can complement Microsoft 365 experiences in PowerPoint, Outlook, and Excel. Through practical examples, the module shows how users can create presentations, catch up on email, analyze data, and refine work with support from Copilot where available.

## Learning objectives

After completing this module, you'll be able to:

- Explain how Microsoft 365 can enhance productivity and data protection for business users on Surface devices.
- Describe how Surface hardware features can support presentation creation and refinement in PowerPoint.
- Identify ways to use Copilot in Outlook to summarize email threads, draft replies, and prepare meeting agendas.
- Use Copilot in Excel to ask questions about data, generate insights, and create visuals for stakeholder review.
