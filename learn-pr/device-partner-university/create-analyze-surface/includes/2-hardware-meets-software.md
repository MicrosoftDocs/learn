Microsoft 365 and Surface work together by combining trusted productivity apps, cloud-connected collaboration, and purpose-built hardware in a unified experience. Microsoft 365 provides the apps and services people use every day—such as Outlook, Excel, Word, PowerPoint, Teams, OneDrive, and Copilot—while Surface provides the device capabilities that make those experiences feel more natural and flexible. Features such as touch, pen input, Studio Microphones, high-resolution PixelSense displays, and adaptable form factors give users more ways to capture ideas, review content, communicate clearly, and move between focused work, meetings, and collaboration.

This better-together experience helps business users stay productive across common workflows. A user can dictate ideas using Surface microphones, refine them with Copilot in Microsoft 365, annotate or reorganize content with pen and touch, and review the final result on a clear PixelSense display. At the same time, Microsoft 365 supports secure access, file sharing, and collaboration so work can continue across locations and devices. The scenarios in this module show how Surface hardware and Microsoft 365 software can complement each other in practical tasks such as building presentations, catching up on email, and analyzing data.
