In this module, you'll explore Microsoft Ink Canvas—an AI-powered, pen-first interaction experience for Microsoft Surface devices. You'll learn what Ink Canvas is, how to access it on your Surface device, how it is optimized for Surface hardware experiences, and explore use cases where Ink Canvas can create an efficient workflow.

## Learning objectives

By the end of this module, you'll be able to:

- Describe how Ink Canvas uses ink and AI to transform ideas into content.
- Differentiate Ink Canvas from OneNote and Microsoft Whiteboard based on their core purposes and workflows.
- Access and configure Ink Canvas on supported Surface and Windows devices.
- Explain how Surface Slim Pen and Surface hardware enhance the Ink Canvas experience.
- Use Ink Canvas tools and AI capabilities to create, refine, summarize, and reuse content in Microsoft 365 workflows.
