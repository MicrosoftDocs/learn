Before recommending or demonstrating Ink Canvas, validate the customer's device, pen, Windows configuration, installation path, and access to AI features. The checks below help partners distinguish app availability from readiness to use the intended workflow.

- **Device and pen:** Use a pen-capable device with a supported pen. Check the exact device and pen combination in the compatibility guidance; a touchscreen alone does not establish pen support, and pen features vary by model.
- **Windows and installation:** Check the current app requirements in Microsoft Store on the target device and confirm that installation is permitted in the customer's environment. Ink Canvas is preinstalled on Surface Pro 12-inch (2nd Edition); other supported devices require a Microsoft Store download.
- **Pen shortcut:** A single click of the Slim Pen shortcut button opens a new canvas by default on Surface Pro 12-inch (2nd Edition). On other supported devices, configure the shortcut after installation in Windows Settings. Test the shortcut before a demonstration.
- **Feature access:** Core inking works offline and does not require Copilot access. AI features require an eligible Microsoft 365 subscription and are subject to usage limits. Confirm access with the account that will be used for the demonstration.

## Microsoft Surface Pro for Business, 12-inch (2nd Edition)

Ink Canvas is a built-in experience on all Microsoft Surface Pro, 12-inch (2nd Edition) devices—meaning that there is no extra step to download the software. To activate the feature, a single click of the Slim Pen shortcut button opens a new canvas, giving users a direct way to capture an idea the moment it starts.

>[!NOTE]
> Surface Slim Pen is not included with Microsoft Surface Pro, 12-inch (2nd Edition) and is sold separately.

## Other Surface devices

On other supported Surface devices that meet the app requirements and support the intended pen, download Ink Canvas from the Microsoft Store. Do not assume that every Surface model with a touchscreen supports the same pen experience. Verify the configuration using the readiness checks above, then follow these steps:

1. On your Surface home screen, select **Start**.
2. Select **Microsoft Store**.
3. In the Search box, type "**Ink Canvas**".
4. Select **Get**.
5. Once installation is complete, select **Open**.

Once installed, ensure that your shortcut button is configured manually in Windows. To do so, do the following:

1. Open **Settings**.
2. Select **Bluetooth & devices**.
3. Select **Pen & Windows Ink**.
4. Select **Choose what your shortcut button does**.
5. Choose whether you want to trigger Ink Canvas with a single click, double click, or press and hold gesture.
6. Select **Open an app**.
7. Select **Ink Canvas**.

>[!NOTE]
> Ink Canvas is also available from Microsoft Store for other supported Windows devices. Before recommending it, check the current Windows and hardware requirements in the Store listing on the target PC, confirm a supported device-and-pen combination, and verify the customer's installation and account requirements. App installation and eligibility for Copilot-powered features are separate checks.
