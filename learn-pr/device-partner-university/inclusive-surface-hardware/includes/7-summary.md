In this module, you learned how inclusive Surface hardware features can help reduce barriers for users with different mobility, vision, and input needs. You explored how Adaptive touch mode, haptic touchpads, and the Bold keyset can support more reliable input, clearer feedback, and greater confidence during everyday workplace tasks.

## Key takeaways

- Review supported Surface device options to identify hardware features that align with users' mobility, vision, and input needs.
- Enable and adjust Adaptive touch mode when users need more reliable touchpad input based on how they naturally interact with their device.
- Use haptic touchpad feedback to help users confirm clicks, gestures, alignment, and other interactions with greater confidence.
- Consider the Bold keyset for users who benefit from larger, high-contrast key legends and tactile landmarks during typing or screen reader workflows.
