Moving between an active task and another tool can add extra steps to a workflow. Surface Mouse (2nd Edition) includes a customizable action button that provides another way to access Copilot experiences, Windows tools, and other shortcuts directly from the mouse.

The action button supports different commands based on how the button is pressed.

## Choose an action for your task

Different tasks can benefit from different action button interactions. By default, the action button provides different shortcuts based on how you press it:

- Press once to open **Snipping Tool**.
- Press twice to open **Click to Do**. If Click to Do isn't available, the Start menu opens instead.
- Press and hold to open **Copilot Voice**. If Copilot Voice isn't available, Task view opens instead.

You can customize these actions in the Surface app to better match your workflow. To do so, do the following:

1. Open the **Surface app**.
2. Select the Surface Mouse from the available devices.
3. Select **Customize mouse**.
4. Use **Action button settings** to change what the button does.

## Customize the button around your workflow

Copilot experiences aren't the only option available through the action button. The button can also be customized to access common tools such as Snipping Tool or to use custom shortcuts. When deciding how to use the button, consider the tools and actions you access regularly:

1. Identify a tool or action you frequently use.
2. Consider whether assigning that tool or action to the customizable button would fit in your workflow.
3. Customize the button for your preferred workflow using the supported options available for the mouse.

>[!NOTE]
> When assigning a custom shortcut to the action button, the shortcut must be a supported Windows keyboard shortcut. Check out a full list of Windows keyboard shortcuts on [Microsoft Learn](/answers/questions/3964470/73-keyboard-shortcuts-in-windows) to explore more.

## Put the action button into practice

Consider a user who regularly moves between creating content and using AI-assisted tools. Instead of treating the action button as simply another mouse control, the user can choose an interaction based on what needs to happen next.

For example, the user could configure the action to button to press the button once to access Copilot, twice to access Click to Do, or press and hold to access Copilot Voice. Alternatively, the user can customize the button for another frequently used tool, such as Snipping Tool.

**Key takeaway:** The customizable action button provides access to Copilot experiences and other shortcuts directly from the mouse. By choosing an interaction or customization that reflects a frequently performed task, users can keep common tools closer to the work they do every day.
