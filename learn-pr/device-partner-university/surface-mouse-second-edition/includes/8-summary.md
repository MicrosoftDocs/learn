Surface Mouse (2nd Edition) combines a redesigned form, integrated haptic feedback, multi-host connectivity, and a customizable action button to support different Surface workflows. Throughout this module, you explored how these capabilities can support everyday mouse interactions, provide tactile feedback during supported experiences, provide access to frequently used tools, and fit into routines that include more than one PC.

## Key takeaways

- Surface Mouse (2nd Edition) features a redesigned, compact form factor, silicone top cover, quiet clicks, and familiar scrolling controls for everyday use.
- Integrated haptic feedback provides tactile cues during supported Windows and application interactions, including snapping or resizing windows and aligning or rotating images in PowerPoint.
- The customizable action button provides access to Copilot experiences and other supported shortcuts, allowing users to adapt the button to their workflows.
- Multi-host connectivity supports connections with up to three computers, which can be useful when a workflow regularly includes more than one PC.
- By considering the task first, users can determine which mouse capabilities best fit the way they work.
