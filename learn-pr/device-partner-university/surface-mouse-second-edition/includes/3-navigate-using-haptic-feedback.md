Traditional mouse interactions rely primarily on what you see on screen. Surface Mouse (2nd Edition) adds another form of feedback through integrated haptics, providing subtle tactile cues during supported interactions in Windows and certain applications.

These cues reinforce actions as they happen. For example, the mouse can provide haptic feedback during supported Windows interactions such as hovering, snapping, or resizing windows. Supported experiences in applications such as PowerPoint can also provide feedback when aligning or rotating images. Tactile feedback can be especially useful when a user is focused on precise placement or multitasking and wants confirmation without relying only on visual changes on screen.

## Understand when haptic feedback is available

Haptic feedback works alongside visual information on the screen. Rather than changing how you point, click, or drag the mouse, haptics can reinforce supported interactions with a tactile response.

For example, haptic feedback can help reinforce supported interactions when you:

- Hover over supported interface elements.
- Snap or resize windows.
- Align and rotate images in Microsoft PowerPoint.
- Utilize supported third-party application. See the full list of supported applications on [Microsoft Support](https://support.microsoft.com/en-us/surface/accessories/mouse-keyboard/use-surface-mouse-2nd-edition).

This extra feedback provides another way to recognize when a supported action happens on screen.

## Try haptic feedback during a supported interaction

One way to understand the experience is to note haptic feedback while completing a supported action. For example, when working with an image in PowerPoint:

1. Open a PowerPoint presentation and select an image, shape, or text box.
2. Slowly move the object across the slide.
3. Position the object so that it aligns with another element on the slide.
4. Notice the haptic feedback as you reach supported alignment points.
5. Compare the tactile feedback with the visual alignment information displayed in PowerPoint.

## Customize the haptic experience and put it into practice

You can adjust haptic feedback to a level that works for you:

1. Open **Settings** and select **Bluetooth & devices**.
2. Select **Mouse**.
3. Select **Haptic signals**.
4. Adjust the **Signal intensity slider** to your preferred level.

If you don't see the haptic signal settings, you may need to update Windows.
