Diagnosing hardware issues can be an important first step in determining how to restore a Surface device to working condition. Surface Repair Tool (SRT) provides a guided experience for diagnosing hardware issues and completing supported repair workflows on Surface devices. 

It combines interactive hardware diagnostics with step-by-step Field-Replaceable Unit (FRU) repair workflows, helping users validate hardware functionality before and after a repair.

In this module, you'll learn how to navigate Surface Repair Tool, select and run appropriate diagnostics, interpret test results, and understand how SRT supports a guided repair workflow.

## Learning objectives

By the end of this module, you'll be able to:

- Describe how Surface Repair Tool supports hardware diagnostics and guided repairs.
- Navigate Surface Repair Tool and identify its primary diagnostic and repair capabilities.
- Select and run diagnostic tests based on a Surface device's hardware issue.
- Interpret diagnostic results and determine appropriate next steps.
- Explain how SRT supports repair validation, calibration, and post-repair functionality testing.
