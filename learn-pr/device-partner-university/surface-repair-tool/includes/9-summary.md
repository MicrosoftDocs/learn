Surface Repair Tool (SRT) provides a guided experience for diagnosing hardware issues and supporting repairs on compatible Surface devices. In this module, you learned how to access and navigate SRT, select and run hardware diagnostics, review test results, and use guided repair workflows to support hardware replacement and post-repair validation. You also explored where to find additional troubleshooting, repair documentation, and application settings when you need more information.

## Key takeaways

- Use **Test** to select and run diagnostics for Surface hardware components and subsystems.
- Follow the instructions provided by SRT during each diagnostic, including any required device interactions, environmental changes, or hardware preparation.
- Review the **Test Results** page to identify pass or fail outcomes, view detailed results, rerun tests, and access available fix options.
- Use supported **Repair** workflows to prepare for hardware replacement and complete post-repair validation, calibration, and functionality testing as applicable.
- Use **Support** to access additional troubleshooting guidance and Surface repair documentation, and **Settings** to manage application and diagnostic preferences.
