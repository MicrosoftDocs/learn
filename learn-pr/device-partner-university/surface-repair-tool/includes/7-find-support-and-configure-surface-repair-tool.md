Surface Repair Tool (SRT) includes **Support** and **Settings** areas that complement its diagnostic and repair workflows. Use these areas to find additional troubleshooting and repair resources, review available help, and manage application preferences.

## Find support resources

If an issue can't be resolved through diagnostics or a guided repair workflow, select **Support** from the left navigation menu.

The Support section provides access to:

- Troubleshooting guidance for common Surface hardware and software issues.
- The Surface Service Repair Guide and other official repair documentation.
- Help resources and escalation paths for issues that can't be resolved through self-service.

## Access additional support

To find additional guidance in SRT:

1. Select **Support** from the left navigation menu.
2. Review the available troubleshooting guidance for the issue you're investigating.
3. Open the **Surface Service Repair Guide** or other available documentation when you need detailed repair guidance.
4. Use the available help resources or escalation paths when the issue can't be resolved through self-service.

The Surface Service Repair Guide can also be accessed from the informational cards on the SRT Home page.

## Review SRT settings

Select **Settings** from the left navigation menu to access application configuration options.

From Settings, you can:

- Configure general application behavior and preferences.
- Manage diagnostic run preferences.
- View the SRT version and build information.

## Review diagnostic preferences and application information

1. Select **Settings** from the left navigation menu.
2. Review the available general application preferences.
3. Review or manage the available diagnostic run preferences.
4. View the tool version and build information when needed.

## Know where to go next

As you work with SRT, use each area of the tool according to the task you're completing:

- Use **Test** to run hardware diagnostics.
- Use the **Test Results** page to review outcomes, rerun tests, and access available fix options.
- Use **Repair** to begin supported FRU replacement workflows.
- Use **Support** when you need additional troubleshooting, repair documentation, or help resources.
- Use **Settings** to review application and diagnostic preferences or identify the installed version and build.

Together, these areas provide a path from identifying a potential hardware issue through diagnosis, repair support, validation, and additional troubleshooting resources.
