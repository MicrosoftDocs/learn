Before you can diagnose a hardware issue, or begin a supported repair, familiarize yourself with how to access and navigate Surface Repair Tool (SRT). SRT provides different access options depending on your role and a central Home page for starting diagnostic and repair workflows.

## Access Surface Repair Tool

How you access SRT depends on your role.

Consumer and commercial end users can install Surface Repair Tool from the Microsoft Store by doing the following:

1. Open the **Microsoft Store**.
2. Search for **Surface Repair Tool**.
3. Select **Get** to download and install the application.
4. After installation, launch SRT from the **Start menu**.

If you have the Surface app already installed, you can also access SRT from the app by doing the following:

1. Open the **Surface app**.
2. Select **Help & Support**.
3. Navigate to **Troubleshoot basic issues**.
4. Select the option to open **Surface Repair Tool**.

Commercial IT administrators can access SRT through the Surface IT Toolkit. To do this, follow these steps:

1. Open Surface IT Toolkit on the device or management workstation.
2. Select the Surface Repair Tool module.
3. Launch it to begin diagnostics or a guided repair workflow.

This access method is recommended when standardized diagnostic or troubleshooting workflows are required.

Authorized Service Providers (ASPs) can download SRT from the Microsoft Download Center and launch it from their service workstation to perform diagnostics and repair operations.

>[!NOTE]
> When SRT launches, it automatically checks whether the current device is supported. If the device isn't supported, continue using Surface Diagnostic Toolkit (SDT) for diagnostics and troubleshooting.

## Navigate the Home page

:::image type="content" border="true" source="../media/surface-repair-home-page.png" alt-text="Screenshot of the home page of Surface Repair Tool, featuring device information, battery information, and buttons to run a test or start a repair.":::

After you launch SRT, the Home page provides the central starting point for working with the tool. From here, you can choose between two primary actions:

- **Run a test** opens the hardware diagnostic experience.
- **Start a repair** begins a guided Field-Replaceable Unit (FRU) repair workflow.

The Home page also provides information that can help you understand the current state of the device, including:

- **Device information** for the device model, hardware configuration, and system identifiers.
- **Battery information** for current battery status and health indicators.
- **Windows Update** for the current operating system update state.
- **Surface Service Repair Guide** for access to official Surface repair documentation.

## Choose where to start

Suppose a Surface device isn't charging as expected. After launching Surface Repair Tool and reviewing the device information on the Home page, select **Run a test** to investigate the issue. Choose the appropriate battery diagnostics, follow the guided steps, and review the results. If the results identify a supported hardware issue and a repair workflow is available, select **Start a repair** to continue.

Use the same approach for other hardware issues: begin with **Run a test** when you need to diagnose a possible problem, and use **Start a repair** when you've identified a supported component that needs replacement.

## Navigate between SRT experiences

You can also use the persistent left navigation menu to move between the primary areas of SRT:

- Home: View device information and access quick-launch actions.
- Repair: Access guided FRU replacement workflows.
- Test: Access hardware diagnostics.
- Support: Find troubleshooting guidance and help resources.
- Settings: Configure application and diagnostic preferences.

Understanding these areas helps you move through SRT based on the task you're trying to complete instead of navigating through each section in sequence.
