Windows 11 works together with solutions such as [Microsoft Intune](https://www.microsoft.com/security/business/microsoft-intune?msockid=11a2d20a03fb61e02999c4f502ab6048) and [Microsoft Agent 365]( https://www.microsoft.com/microsoft-agent-365?msockid=11a2d20a03fb61e02999c4f502ab6048) to help organizations manage, govern, and secure AI experiences and agents across devices and users. These tools can help IT teams establish policies, manage configurations, and maintain visibility as AI capabilities are introduced.

> [!TIP]
> Want to learn more about Microsoft Agent 365? Visit the [Microsoft Agent 365 Adoption Hub](https://adoption.microsoft.com/ai-agents/microsoft-agent-365/) for guidance, documentation, and resources covering agent governance, security, adoption, and management best practices.

Microsoft Intune helps IT teams manage device settings, applications, and access policies across Windows devices. Microsoft Agent 365 helps organizations onboard agents through IT-controlled workflows and apply security policy templates so that agents start secure, governed, and compliant from the beginning. Organizations might use Microsoft Intune to manage and control AI experiences across managed devices, while Microsoft Agent 365 can help govern and manage AI agents introduced across the business.

## Governance and deployment considerations

| Solution or capability | Primary purpose | Licensing considerations | Hardware considerations | Availability considerations |
| ------------------------ | ----------------- | -------------------------- | ------------------------- | ----------------------------- |
| **Microsoft Intune** | Manage devices, applications, access policies, and AI experiences | Microsoft Intune licensing required | Supported managed devices | Requirements vary by scenario |
| **Microsoft Agent 365** | Govern, secure, onboard, and manage AI agents | Requirements vary by deployment scenario | Requirements vary by deployment scenario | Availability and capabilities vary by feature |
| **AI experiences in Windows 11** | Deliver AI-powered productivity experiences to users | Some experiences require separate subscriptions | Some experiences require Copilot+ PCs | Availability, languages, and release status vary by feature |

> [!NOTE]
> Microsoft Intune, Microsoft Agent 365, and some AI experiences might require separate licenses. Availability and requirements vary by feature.

When governance is integrated into day-to-day management processes, IT can help provide AI experiences that are consistent, trustworthy, and aligned with organizational policies. Employees can then spend less time evaluating tools and more time using approved AI capabilities to complete their work.
