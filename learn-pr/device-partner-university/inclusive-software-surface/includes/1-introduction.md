Inclusive technology helps people work in the ways that best support their abilities, environments, and daily tasks. In this module, you'll explore how Windows accessibility features on Surface devices can help reduce common workplace barriers across vision, hearing, comprehension, mobility, and input. You'll learn how these tools can support more accessible and productive experiences. As you review each feature, focus on the practical decision-making approach of identifying the user barrier, choosing the right accessibility tool, and connecting that choice to a meaningful workplace outcome.

## Learning objectives

By the end of this module, you should be able to:

- Identify common workplace accessibility barriers across vision, hearing, comprehension, mobility, and input.
- Describe how Windows accessibility features on Surface devices support inclusive and productive user experiences.
- Match accessibility tools, such as Contrast themes, Magnifier, Narrator, Live Captions, Voice Access, Voice typing, Fluid Dictation, and Eye control, to user needs and work scenarios.
- Evaluate feature availability, device requirements, and configuration considerations when recommending accessibility experiences for Surface users.
