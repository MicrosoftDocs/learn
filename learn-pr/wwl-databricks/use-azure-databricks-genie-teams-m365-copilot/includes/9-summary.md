In this module, you explored how Azure Databricks Genie makes your organization's data accessible inside Microsoft Teams and Microsoft 365 Copilot—without requiring any technical skills or SQL knowledge.

## What you learned

- **Genie surfaces:** Azure Databricks Genie is available through Genie Agents, Genie One, the Genie mobile app, the Databricks Genie app in Microsoft Teams, and Genie on Microsoft 365 Copilot. Choose the surface that best fits where you're working.
- **Using Genie in Teams:** You can access Genie through a direct message or by mentioning `@Databricks Genie` in a channel. The Teams app supports natural-language questions, multi-turn conversations, sources, suggested follow-up prompts, feedback to Genie One, and chart images. Charts aren't shown in private-visibility replies.
- **Using Genie in Microsoft 365 Copilot:** You can open a Genie conversation via **More agents** or invoke Genie with `@Databricks` in a new chat. The recommended Teams-app connection shares the documented integration limitations. File uploads are available only in Teams direct messages, not in Copilot.
- **Asking effective questions with SPARK:** The SPARK framework (Scope, Period, Aggregation, Result, Key metric) helps you build specific questions that reduce ambiguity and produce reliable answers. Multi-turn follow-up questions build on earlier context within the same thread.
- **Interpreting and verifying answers:** The inspect-verify-refine workflow—checking filters, reviewing source citations, spotting anomalies, and following up on uncertain answers—helps you translate a Genie response into a decision with confidence.
- **Using AI-generated answers responsibly:** Chat mode focuses on factual data questions, while Agent mode can investigate patterns and causes. Neither AI-generated explanations nor trusted assets guarantee a correct result. Consider visibility when sharing answers in channels, and escalate to a domain expert or your data team for high-impact or anomalous findings.
