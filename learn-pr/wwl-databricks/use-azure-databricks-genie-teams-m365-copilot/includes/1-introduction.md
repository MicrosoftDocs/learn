Your organization stores its operational data in Azure Databricks. When a data question comes up in a meeting or a chat thread, you don't want to wait for a report or hand it off to someone else—you want an answer now, in the tool you're already using.

## The challenge Sofia faces

Sofia is a regional sales manager at Contoso Bakehouse, a fictional artisan bakery chain. She's in a Microsoft Teams meeting when a stakeholder asks about Q1 sales by country/region. The data exists in Azure Databricks, but Sofia doesn't write SQL and doesn't have time to switch to another tool. She needs a reliable answer in the next few minutes, right inside Teams.

Azure Databricks Genie makes that possible. Genie is a natural-language interface to your organization's data. Sofia's organization has set up Genie Agents—domain-specific data assistants—so that business users like Sofia can ask data questions in plain language and get trustworthy answers without needing any technical skills.

## What this module covers

In this module, you explore the different surfaces where Genie is available—from Azure Databricks itself to the Databricks Genie app in Microsoft Teams and Microsoft 365 Copilot—so you can recognize where Genie shows up in your own workflow. You learn how to ask effective questions using the SPARK framework, how to read and verify the answers Genie gives you, and how to use those answers responsibly to support better decisions.

By the end of this module, you're able to use Genie confidently within Microsoft Teams and Microsoft 365 Copilot to get fast, trustworthy answers to your data questions—without writing a single line of code.
