Your security team is ready to use Perception, but enabling an agent doesn't guarantee that security practitioners can use it. The agent needs access to the data its work requires, and security practitioners need permission to start sessions, respond to requests, and retrieve results.

## Set up an agent for your team

Setup brings those pieces together. You configure the agent, confirm the required access, and test that the people using it can complete the security task with their own accounts.

This module explains how to configure the Threat Intelligence Agent so security practitioners can use the Extract threat intelligence playbook to extract threats, indicators, and next steps from a threat article. The procedures cover access checks and testing patterns that extend to other agents and playbooks.

## Learning objectives

In this module, you learn how to:

- Turn an approved task into setup requirements and acceptance criteria.
- Configure the agent identity and check its required permissions.
- Confirm required services and security practitioner access separately.
- Test the approved task, diagnose an access failure, and retest after correction.
- Record the readiness decision, limitations, and operational owner.
