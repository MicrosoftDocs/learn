Your configuration work is complete when the required access is confirmed and a security practitioner demonstrates the approved task. An agent marked Enabled is a starting point, not proof of readiness.

Approved task → required agent → agent and security practitioner access → testing → handoff

In this module, you learned how to:

- Turn an approved task into setup requirements and acceptance criteria.
- Configure the agent identity and check its required permissions.
- Confirm required services and security practitioner access separately.
- Test the approved task, diagnose an access failure, and retest after correction.
- Record the readiness decision, limitations, and operational owner.

Use the approved task and test evidence to record configuration readiness and arrange the handoff through the organization's approval process. Keep unresolved requirements visible, and retest after a correction that affects readiness. A working configuration still leaves the security practitioner responsible for reviewing the findings from each session.
