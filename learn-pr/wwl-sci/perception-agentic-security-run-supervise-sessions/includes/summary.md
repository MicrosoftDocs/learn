The team needs an answer it can rely on, whether the request concerns a threat report, an incident, or security issues to fix. Perception can carry out that work, but the agents' output still needs your review before the team uses it.

In this module, you learned how to:

- Identify the needed security outcome and choose an appropriate playbook.

- Confirm the required input and access, start a session, and follow its progress.
- Respond to agent requests and redirect or stop work when appropriate.
- Review the session findings against the available evidence and the original request.
- Record what can be used, what remains unresolved, and who acts next.

Before sharing findings, check what ran and which conclusions the evidence supports. Respond to requests while work is active, and keep missing data or unfinished analysis visible in the handoff. A completed session gives you output to review. The next step depends on what that output establishes.
