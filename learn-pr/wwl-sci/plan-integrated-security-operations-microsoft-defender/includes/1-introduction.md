Security operations teams often use separate tools for signals, investigations, automation, and response. Integrated Security Operations Center (ISOC) in Microsoft Defender brings extended detection and response (XDR), security information and event management (SIEM), threat intelligence, automation, and AI together in the Microsoft Defender portal.

## Why organizations consider ISOC

Consider a security operations team that needs shared investigation context, consistent case ownership, reporting, and repeatable response workflows. Its first priority is case ownership and reporting, with additional data only when an approved operational need justifies it.

Eligible customers start with built-in capabilities without first deploying a traditional SIEM. When broader visibility supports an operational need, a workspace adds supported Microsoft and non-Microsoft data through connectors. Additional ingestion charges might apply.

These reasons guide capability choices rather than justify adopting every feature. Your team retains responsibility for priorities, approvals, access, and response decisions. Because ISOC is in preview, you also account for changes in eligibility, capabilities, and availability.

## Plan before implementation

This module introduces the operating model and the decisions that shape adoption. You examine preview eligibility, licensing, and permissions before distinguishing built-in capabilities from those that require an ISOC workspace. You then consider native Defender data, additional data sources, access, retention, costs, and operational ownership.

You connect those choices in a phased plan with outcomes, owners, validation measures, and decision gates. The focus stays on recognizing requirements and explaining planning choices, not on deploying resources. You don't create a workspace, configure connectors, or build automation in this module.

By the end of this module, you can describe an ISOC adoption approach that matches operational needs to capabilities and accounts for preview readiness, workspace requirements, data governance, and cost.
