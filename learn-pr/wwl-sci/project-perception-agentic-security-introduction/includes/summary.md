Project Perception is Microsoft's agentic security system, built for a moment when attackers move faster than manual defense can respond. Specialized agents each handle a piece of security work, connected by a shared context layer and sequenced through coordinated playbooks. Approval gates keep humans in control of critical decisions. All of it sits in the **Agentic security** section of the Microsoft Defender portal.

In this module, you learned how to:

- Describe Project Perception and the problem it addresses
- Recognize the shape of multi-agent defense
- Recognize the core capabilities Project Perception provides today
