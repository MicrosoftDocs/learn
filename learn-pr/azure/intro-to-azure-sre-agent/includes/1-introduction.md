Suppose you're part of an on-call team responsible for several Azure workloads. When an alert fires, engineers move among monitoring tools, deployment history, incident systems, and team runbooks before they can form a reliable explanation. Recurring checks and familiar mitigations also consume time that the team could spend improving the service.

Your team is considering Azure SRE Agent, but you need to understand what it does, how it controls access and actions, and whether it fits your operational and governance requirements.

In this module, you explore Azure SRE Agent and evaluate when to use it for reliability engineering work.

## Learning objectives

By the end of this module, you'll be able to:

- Describe Azure SRE Agent and the operational challenges it addresses.
- Explain how Azure SRE Agent investigates issues, automates work, and controls access to resources.
- Evaluate whether Azure SRE Agent is appropriate for your reliability engineering scenarios.
