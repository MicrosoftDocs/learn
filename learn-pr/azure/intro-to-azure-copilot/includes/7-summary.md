Azure Copilot lets Cloud Operations teams describe goals in natural language, work faster across many Azure services, generate scripts they can review and run, troubleshoot issues, and find recommendations—all while respecting each person's existing permissions and requiring confirmation before it acts. 

Azure Copilot can help you navigate the hundreds of services and thousands of resource types that Azure offers. It unifies knowledge and data across hundreds of services to increase productivity, reduce costs, and provide deep insights.

In this module you learned how to:

- Describe what Azure Copilot is and the problems it helps you solve.
- Explain how Azure Copilot works within the Azure portal and respects your permissions.
- Identify the capabilities of Azure Copilot and the scenarios they support.
- Evaluate when to use Azure Copilot and recognize its current limitations.
