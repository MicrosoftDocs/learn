Azure Copilot amplifies your impact by using AI-enhanced operations. You can ask for help with designing, operating, optimizing, and troubleshooting your Azure apps and infrastructure. The following sections describe some of the most common ways you can use Azure Copilot.

## Perform tasks

You can use Azure Copilot to perform many tasks across Azure. These tasks fall into a few broad areas:

- **Understand your Azure environment.** Get resource information through Azure Resource Graph queries, understand service health events and status, analyze and optimize costs, visualize network topology, and query your attack surface.
- **Work smarter with Azure services.** Execute commands, deploy and manage virtual machines, discover and deploy workload templates, work with Azure Kubernetes Service (AKS) clusters, get information about Azure Monitor metrics and logs, manage and migrate storage accounts, troubleshoot disk performance, and design, troubleshoot, and secure networks.
- **Write and optimize code.** Generate Azure CLI scripts, generate PowerShell scripts, generate Terraform and Bicep configurations, author API Management policies, and create Kubernetes YAML specification files.

## Get information

From anywhere in the Azure portal, you can ask Azure Copilot to explain Azure concepts, services, or offerings. You can ask how a feature works or which configuration best meets your budget, security, and scale requirements. Azure Copilot can guide you to the right experience, or even author scripts and other artifacts you can use to deploy your solutions. Answers are grounded in the latest Azure documentation, so you get up-to-date guidance just by asking.

## Solve problems and troubleshoot resources

Asking questions can be especially helpful when you troubleshoot. For example, you can describe a symptom like "Azure database unable to connect from Power BI," and Azure Copilot responds with information about the problem and possible ways to fix it. You can ask for a summary of a diagnostics page, ask what an error means, or ask what the next steps are to implement a recommended solution. In some cases, Azure Copilot can help you resolve the issue directly.

## Find recommendations

Azure Copilot can surface Azure Advisor recommendations across the Well-Architected Framework pillars: Reliability, Cost Optimization, Operational Excellence, Performance Efficiency, and Security. You can ask for general recommendations or focus on a specific area, such as cost savings or security enhancements. You can also ask which services help support your objectives—for example, "What service would you recommend to implement distributed caching?"

## Navigate and manage the portal

Azure Copilot helps you move through the portal more quickly:

- **Navigate between services.** Ask Azure Copilot to open a service for you instead of searching, or ask which service to use for a task.
- **Manage portal settings.** Confirm or change settings, such as switching between light and dark theme, without opening the **Settings** pane.

## Work across multiple conversations and add context

Azure Copilot supports several productivity features that help you stay organized:

- **Manage multiple conversations.** Start new chats while existing ones continue, then switch between, rename, or delete conversations from the navigation pane.
- **Add context to a conversation.** Select the **Add** icon to share resources, subscriptions, service groups, or resource groups related to your request so that Azure Copilot can give more relevant responses.
