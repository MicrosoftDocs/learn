Suppose you're a cloud administrator on a team that runs a growing number of workloads in Azure. Every week, someone asks you to estimate the cost of a new deployment, write a script to provision virtual machines, explain a confusing service health alert, or track down why an app stopped responding. Azure offers hundreds of services and thousands of resource types, and switching between all the different tools and documentation pages takes time you don't always have.

You've heard that Azure Copilot can help you do more with Azure by letting you describe what you want in plain language. Before you recommend it to your team, you want to understand what it is, how it works, and where it fits.

In this module, you explore Azure Copilot so you can decide whether it's the right tool to help your team work more efficiently.

## Learning objectives

By the end of this module, you're able to:

- Describe what Azure Copilot is and the problems it helps you solve.
- Explain how Azure Copilot works within the Azure portal and respects your permissions.
- Identify the capabilities of Azure Copilot and the scenarios it supports.
- Evaluate when to use Azure Copilot and recognize its current limitations.
