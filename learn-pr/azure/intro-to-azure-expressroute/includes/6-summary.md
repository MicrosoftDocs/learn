In this module, you learned how Azure ExpressRoute provides private, routed connectivity between on-premises networks and Microsoft cloud services. You explored circuits, peering types, connectivity models, and the prerequisites for connecting Azure virtual networks. You also considered how encryption, resiliency, endpoint selection, capacity, and cost affect whether ExpressRoute meets Adatum's needs, and how Azure VPN Gateway can complement or provide an alternative to ExpressRoute.
