The goal of this module was to help you troubleshoot issues of Azure NetApp Files and learn resolutions to issues you might get when managing Azure NetApp Files resources.

You learnt how to troubleshoot Azure NetApp Files resources by:

- Using diagnose and solve problems tool
- Troubleshooting Azure NetApp Files for various issues

You also performed hands-on exercises to use diagnose and solve problem tool, troubleshoot user access on LDAP volumes, and troubleshoot file locks on Azure NetApp Files volumes.
