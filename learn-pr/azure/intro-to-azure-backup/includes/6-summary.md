Our goal was to help you evaluate whether Azure Backup would offer the features and capabilities you need to help you protect your data. During the module, we explored how Azure Backup might address:

* Ensuring availability of your data.
* Protecting your Azure workloads.
* Securing your data.

We applied the criteria to a scenario where your company was hosting an application that used a SQL Server database instance running on multiple Azure VMs. We noted how Azure Backup could provide data protection by backing up our Azure VMs or the files, folders, and system state on those VMs.  

We also saw how Azure Backup helps with compliance by offering retention options for the data and security with encryption and RBAC.

Resiliency provides a unified view to manage and monitor protection across your backup estate. Azure Backup includes security capabilities such as soft delete, immutability, and multi-user authorization. Use the controls supported by your workloads and vaults, and separate backup administration from authorization of protected critical operations. These protections reduce risk; they aren't an unconditional guarantee against ransomware or a compromised administrator.
