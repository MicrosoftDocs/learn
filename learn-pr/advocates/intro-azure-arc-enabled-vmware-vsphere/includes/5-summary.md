You learned how to connect an on-premises vCenter or an Azure VMware Solution private cloud to Azure Arc. Discovery shows what's in vCenter; onboarding lets you delegate access and manage selected VMs and infrastructure. The resource bridge handles virtual hardware operations and needs ongoing maintenance; after upgrading, confirm its version is supported as well as healthy. Offboarding removes Azure management; deleting a VMware VM also removes it from its host. Install the Azure Connected Machine agent when you need to manage the guest OS.

For a connected guest, check each service's OS support and configure its extensions, data collection, and connectivity separately. Check the version, servicing baseline, hosting platform, and licensing terms before enabling Extended Security Updates. ESUs have fixed end dates and don't restore general product support. Confirm Windows ESU enrollment both locally and in Azure. Review all SQL instances and associated services affected by host-level settings, core limits, and back-billing before subscribing. Confirm recurring-billing consent if selecting SQL pay-as-you-go in a CSP-managed subscription. Enrollment doesn't configure patching policy. Keep usage reporting healthy, cancel unneeded SQL ESU subscriptions, and separately reduce or deactivate Windows ESU licenses when coverage is no longer required.
