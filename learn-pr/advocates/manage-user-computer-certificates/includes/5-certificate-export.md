Export public certificates to share identities, distribute approved CA certificates, or support diagnostics. Export a private key only for an authorized backup or transfer that requires it.

To export a certificate using the console, open the appropriate console under the identity authorized to access the certificate and key. For a user certificate, use `certmgr.msc`. For a machine certificate, use elevated `certlm.msc`.

1. In **Personal** > **Certificates**, open the selected certificate and confirm its thumbprint.
1. Open its shortcut menu and select **All Tasks** > **Export**.
1. Select **No, do not export the private key** for a public export. Choose DER, Base64, or PKCS #7 according to the destination.
1. For an authorized key backup, select **Yes, export the private key** and the PFX format. Choose the required chain and extended-property options.
1. Protect a PFX with a strong password and compatible encryption. Leave **Delete the private key if the export is successful** unselected.
1. Save to an access-controlled destination, finish the wizard, and inspect the resulting file.

Use the same decision process in both account contexts. Copying the resulting public certificate to another computer doesn't transfer the key.

## Unavailable private-key export

Private-key export requires an associated key, access to that key, and an export policy that permits the operation. If **Yes, export the private key** not available, identify which of the following requirements isn't satisfied.

- A certificate downloaded from a CA doesn't include the key generated by the requester. 
- A certificate on a smart card can reference a key that remains on the card.
- A TPM-backed key can be deliberately non-exportable.

Exportability is a key property established during certificate creation or import. Don't treat exportability as a cosmetic certificate setting that an administrator can switch on later. An approved re-enrollment or recovery process might be required to enable exportability.

## Export public certificates with certutil

Select an exact certificate by full thumbprint. Confirm that each destination file doesn't already exist before running these commands:

```console
certutil.exe -user -store My "<UserCertificateThumbprint>" "C:\CertWork\user.cer"
certutil.exe -store My "<MachineCertificateThumbprint>" "C:\CertWork\server.cer"
```

The output files contain public certificates, not private-key backups. Inspect each file and compare its thumbprint with the source certificate.

For Base64 output, select **Base-64 encoded X.509** in the wizard or convert an approved DER export explicitly:

```console
certutil.exe -encode "C:\CertWork\server.cer" "C:\CertWork\server-base64.cer"
```

Use the export wizard when the destination requires PKCS #7, a chain, or another container option that needs operator review.

## Export a protected PFX

PFX export requires an accessible, exportable key. Use the export wizard when you need to review chain inclusion, extended properties, and package encryption compatibility. For a controlled native export, select the exact certificate by thumbprint:

```console
certutil.exe -user -exportPFX My "<CertificateThumbprint>" "C:\CertWork\user-backup.pfx"
```

Omit `-user` and use an elevated prompt for a machine certificate. Enter the new PFX password only when prompted; don't place it in command text, scripts, logs, or transcripts. The operation fails when the key is unavailable or non-exportable.

Inspect the PFX with `certutil.exe -dumpPFX`, then prove recoverability through an authorized restore test. Protect the file and password separately, retain approved backups according to policy, and remove unnecessary transfer copies through the approved data-disposal process.
