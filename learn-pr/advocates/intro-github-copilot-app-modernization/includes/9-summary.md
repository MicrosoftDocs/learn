In this module, you learned how GitHub Copilot modernization coordinates application assessment, planning, and reviewable changes. Java and .NET workflows support upgrades and Azure dependency migration, with .NET runtime/framework upgrades documented as GitHub Copilot upgrade. Other scenarios include C++ upgrades, JavaScript/TypeScript dependency upgrades, and Python migration to Microsoft Agent Framework.

Use the integration and prerequisites appropriate to your scenario. For cloud execution that relies on repository setup workflows or Windows/custom runners, choose an Actions session rather than a Cloud sandbox. Review compatible target versions, custom skills, behavioral changes, build/test results, and unresolved vulnerabilities. Treat data movement, service configuration, and production deployment as explicit decisions rather than assuming that generated code completes a migration. Use Azure Managed Redis for forward-looking cache modernization, and select email replacements by recipient scope and delivery requirements rather than treating services as interchangeable. For High Volume Email, include the supported tenant environment, tenant-level SharePoint licensing, dedicated sending account, and service-connected pay-as-you-go billing in the migration plan.
