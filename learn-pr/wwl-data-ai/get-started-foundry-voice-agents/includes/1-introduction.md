Microsoft Foundry Agent Service enables you to build agents that interact with callers through spoken conversation. Along with useful answers, a voice agent needs clear speech and appropriate timing.

Imagine a customer asking whether they can return a product. A returns assistant needs to explain the policy, ask for missing details, and give the customer time to finish speaking. This focused scenario provides a starting point for exploring voice agents without connecting an order system or a telephone service.

In this module, you create a voice agent in the Foundry playground, configure its instructions and voice, and test it with spoken requests. You also compare turn detection settings and make targeted improvements to the conversation.
