AI-assisted coding tools can help you understand an unfamiliar codebase, plan a solution, generate code, investigate defects, and create tests. The model behind the tool has a major influence on how well it performs these tasks.

Microsoft develops the **MAI-Code** model for software development. This model is optimized to understand coding requests, reason about an implementation, and work with development tools to produce and refine code. You use them through an AI-assisted coding experience, such as Microsoft Copilot Code or GitHub Copilot.

In this module, you'll learn:

- What an MAI-Code model is and which development tasks it can support.
- How to select an MAI-Code model in an AI-assisted coding tool.
- How to provide context and instructions that help the model generate useful code.
- How to review and validate AI-generated changes.

You'll then use an MAI-Code model to generate an application in a hands-on exercise.
