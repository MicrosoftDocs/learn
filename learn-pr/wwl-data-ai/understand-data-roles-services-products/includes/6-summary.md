Spreadsheets provide a useful tool for quickly transforming data for analysis. However, services designed for data at scale are necessary to build reliable and timely reporting solutions that can be shared across your organization.

The Microsoft Azure cloud platform offers scalable solutions to host your data, centralize data from multiple sources into a data warehouse, and build reports and dashboards using Power BI.

By completing this module, you can:

 -  Describe data systems.
 -  Understand the fundamentals of Azure data services.
 -  Describe the role and purpose of a data professional.
