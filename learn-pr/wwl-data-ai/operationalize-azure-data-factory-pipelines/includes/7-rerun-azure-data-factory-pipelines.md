To rerun a pipeline that previously ran from the start, hover over the specific pipeline run and select **Rerun**. If you select multiple pipelines, you can use the **Rerun** button to run them all.

![Screenshot of the Rerun option when hovering over a pipeline run in the monitoring view.](../media/rerun-pipeline.png)

If you wish to rerun starting at a specific point, you can do so from the activity runs view. Select the activity you wish to start from and select **Rerun from activity**. 

![Screenshot of the Rerun from activity option in the activity runs view.](../media/rerun-activity.png)

## Rerun from failed activity

If an activity fails, times out, or is canceled, you can rerun the pipeline from that failed activity by selecting **Rerun from failed activity**.

![Screenshot of the Rerun from failed activity option in the activity runs view.](../media/rerun-failed-activity.png)

## View rerun history

You can view the rerun history for all the pipeline runs in the list view.

![Screenshot of the pipeline runs list view showing rerun history.](../media/rerun-history-1.png)

You can also view rerun history for a particular pipeline run.

![Screenshot of the rerun history for a specific pipeline run.](../media/view-rerun-history.png)
