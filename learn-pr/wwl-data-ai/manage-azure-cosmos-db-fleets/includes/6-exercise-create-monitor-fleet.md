In this exercise, you create a fleet and fleetspace, enroll two Azure Cosmos DB accounts in a shared throughput pool, monitor the pool, and send fleet analytics to Azure Data Lake Storage.

> [!NOTE]
>
> To complete this exercise, you need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).

Launch the exercise and follow the instructions.
