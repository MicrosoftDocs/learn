Practice inspecting records and following their relationships in the existing hospital-data exercise. A setup notebook creates the sample lakehouse, eventhouse, and ontology, so you can focus on visualization rather than manually creating the definitions.

The exercise starts in a new workspace on Fabric capacity. It uses the old ontology experience: the **Instances** tab shows records, and **Overview** provides relationship graphs, property charts, and time-series tiles. The concepts of instance identity, relationship paths, and filters transfer to the new experience, but the navigation differs.

> [!NOTE]
> You need access to paid or [trial Fabric capacity](/fabric/get-started/fabric-trial) and permission to create the exercise items. The exercise takes approximately 30 minutes.

Ask a Fabric administrator to confirm the required [tenant settings](/fabric/iq/ontology/overview-tenant-settings):

- **Users can create Fabric items**
- **Users can create ontology (preview) items**
