In this exercise, you mirror an Azure Cosmos DB for NoSQL database into Microsoft Fabric, query the replicated data with Transact-SQL and Spark, and observe a source update reach the analytical copy.

> [!NOTE]
>
> To complete this exercise, you need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn) and an active [Microsoft Fabric capacity](/fabric/fundamentals/fabric-trial) with a workspace assigned to it.

Launch the exercise and follow the instructions.
