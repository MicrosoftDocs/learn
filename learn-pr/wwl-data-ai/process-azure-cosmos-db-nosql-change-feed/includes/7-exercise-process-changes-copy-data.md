In this exercise, you synchronize denormalized data with the change feed, process changes with Azure Functions, and copy data to a container with a different partition key.

> [!NOTE]
>
> To complete this exercise, you need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).
