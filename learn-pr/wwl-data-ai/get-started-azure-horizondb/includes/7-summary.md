This module introduced Azure HorizonDB, a cloud-native, fully managed, AI-ready database service built on PostgreSQL.

## Review what you learned

- **What Azure HorizonDB is**: A fully managed, PostgreSQL-compatible database service for mission-critical workloads, with native support for vector embeddings and Microsoft Foundry integration.
- **How it works**: A disaggregated compute-and-storage architecture and a database-as-a-log design deliver predictable performance, elastic scale, and fast failover while maintaining full ACID guarantees.
- **Cluster components**: A cluster combines a writable primary and readable standby replicas, read-write and read-only endpoints, purpose-built WAL and data storage fleets, and zone-resilient Azure Blob Storage.
- **When to use it**: Azure HorizonDB fits transactional, AI, read-scale, and hybrid workloads. Evaluate current preview limitations and regional availability before you commit a workload.
