In this exercise, you create an Azure Cosmos DB SDK application, connect it to the local emulator, inspect SDK traffic, and then connect the same application to an Azure account.

> [!NOTE]
>
> To complete this exercise, you need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn).
