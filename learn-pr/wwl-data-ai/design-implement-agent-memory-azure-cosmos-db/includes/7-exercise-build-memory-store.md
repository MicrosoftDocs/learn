In this exercise, you build a durable agent memory store, distill and recall long-term facts, inject recalled memory into a prompt, and delete a user's stored memory.

> [!NOTE]
>
> To complete this exercise, you need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn) with access to [Azure OpenAI](/azure/ai-services/openai/overview) and quota for the `text-embedding-3-small` and `gpt-5.4-mini` models.
