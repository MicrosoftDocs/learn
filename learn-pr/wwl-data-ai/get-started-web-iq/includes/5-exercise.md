In this exercise, you'll use Microsoft Web IQ to give an agent in Microsoft Foundry access to current web information. You'll compare answers based on the model's existing knowledge with answers grounded in retrieved web content.

You'll:

- Create a Web IQ resource in Azure and test queries in the Web IQ portal.
- Create a Foundry project and an agent that answers questions about bands and music artists.
- Add the Web IQ MCP tool and configure its connection and approval settings.
- Ask about upcoming concerts, search for images, and inspect traces to verify tool use.

Allow approximately **30 minutes** to complete the exercise.

> [!IMPORTANT]
> You need a paid Azure subscription with permissions to create the required resources and deploy a model. Web IQ doesn't support free trials or subscriptions funded through Azure credits, including MSDN benefit subscriptions. The exercise can incur charges; review its prerequisites and clean-up guidance before starting.
