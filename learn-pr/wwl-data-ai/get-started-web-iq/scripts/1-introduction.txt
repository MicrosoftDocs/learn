In Microsoft Foundry, you can build AI agents that answer questions and help users make decisions. But what happens when an answer depends on something that changed after the model was trained?

An agent might know all about a band's history, but not whether they've just announced a new tour.

In this module, we'll explore Microsoft Web IQ, a service that gives agents access to current information from the web.

You may already be familiar with retrieval-augmented generation, or RAG. Instead of relying only on training data, an agent retrieves relevant information and uses it as context to generate a grounded response.

Web IQ brings that approach to web pages, news, images, and videos, with source information that users can check.

It's part of Microsoft IQ, alongside Work IQ, Fabric IQ, and Foundry IQ.

Let's explore how to configure Web IQ and connect it to an agent in a Foundry project.
