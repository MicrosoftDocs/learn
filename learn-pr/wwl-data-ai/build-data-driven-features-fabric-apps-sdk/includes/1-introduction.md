Data-driven features help people find information and act on it. In a Fabric app, you use a typed client generated from your data model to connect those features to your app's data.

You build the screens for the issue-reporting tool at Adventure Works Cycles. Managers need to find issues by status, browse multiple pages of results, and see how many issues need attention. They also need to update records and attach photos of defective parts. These needs guide how you query, display, and change data in the app.

In this module, you explore how to compose the client and query data, and how pagination, aggregation, and mutations behave. You learn how to store files in a Storage folder under the same permissions as your data. Hands-on exercises in your own Fabric workspace let you build a list, compare single-page results with paginated results, change records, and attach files.

By the end of this module, you're able to build app features that read, change, and store data through the typed Fabric Apps client.
