Now it's your chance to convert an Oracle schema to Azure Database for PostgreSQL flexible server.

In this exercise, you use the PostgreSQL extension for Visual Studio Code to create a migration project, run a schema conversion that uses a Foundry model, review the conversion report, and resolve a Mandatory review task with GitHub Copilot agent mode.

> [!NOTE]
> To complete this exercise, you'll need access to an Oracle database to use as the migration source.

Launch the exercise and follow the instructions.
