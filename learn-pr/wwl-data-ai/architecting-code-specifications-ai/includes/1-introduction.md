An AI coding assistant generates code from the instructions you give it. When the instructions are vague, the result often doesn't match what you need, and you spend time correcting it or generating it again.

A **specification** is a precise description of what code should do. Specifications help human teammates and AI assistants. They matter more with AI, because an assistant works only from the text you provide and might guess at any detail you leave out.

This module teaches you to:

- Break a feature request into clear components.
- Write explicit specifications that describe inputs, processing, outputs, and errors.
- Define edge cases so that no situation is missed.
- Use specifications to write more effective prompts for AI assistance.

The goal isn't to write long documents. A good specification is clear enough that anyone who reads it, human or AI, knows exactly what to build.
