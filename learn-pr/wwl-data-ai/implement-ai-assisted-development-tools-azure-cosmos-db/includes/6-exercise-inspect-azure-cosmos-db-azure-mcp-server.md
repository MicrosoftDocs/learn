In this exercise, you connect an AI assistant to the CosmicWorks product catalog through a Model Context Protocol server, query the catalog with natural-language requests, and inspect the tool calls and results.

> [!NOTE]
>
> To complete this exercise, you need an [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account?cid=msft_learn) and a [GitHub account](https://github.com/signup) with access to [GitHub Copilot](https://docs.github.com/copilot/get-started/plans).

Launch the exercise and follow the instructions.
