C# programs often need to respond differently depending on the situation—checking a game's outcome, applying a discount, or displaying a personalized message. Decision logic lets your code choose which instructions to run.

In this module, you learn how to evaluate conditions with Boolean expressions and comparison operators, use `if`, `else if`, and `else` statements to control the flow of your code, and combine conditions with logical operators. You put these skills together to build a dice game and solve a subscription renewal challenge.

::: zone-end
