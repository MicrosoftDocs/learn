In this module, you learned how to write code that's reusable, organized, and easier to maintain.

You defined methods with parameters, including optional parameters with default values and named arguments. You returned values with `return`, including multiple values using tuples, and saw why a void method can't return a usable result. You explored how local and block scope work, and why passing parameters and return values keeps methods independent. Finally, you organized code using namespaces and the using directive.
