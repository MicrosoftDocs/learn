
Most programs need to work with data. Sometimes that data is hard-coded (like a greeting message), and sometimes it comes from users or other sources. In this unit, you learn about literals (hard-coded values) and variables for storing data. By the end, you'll know how to work with different data types and use them in your programs.

## Learning objectives

In this module, you will:

- Create literal values for common data types (string, int, decimal, bool, char)
- Declare and initialize variables
- Assign and retrieve values in variables
- Use the `var` keyword for implicit typing
