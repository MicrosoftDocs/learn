So far, each variable you've worked with has held a single value. But most real programs need to manage groups of related values, like a list of scores, a shopping cart, or a roster of players. C# provides two essential ways to organize this kind of data: **arrays** and **list** collections.

In this module, you learn how to store a fixed-size sequence of items in an array and access them by index, how to store a resizable sequence of items in a list and add or remove items as your program runs, and how to decide which structure fits a given problem.
