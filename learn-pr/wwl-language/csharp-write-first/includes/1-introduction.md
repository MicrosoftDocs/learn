C# is a popular programming language used to build many types of applications, from web apps to games to cloud services. The best way to learn C# is to write code yourself, so get ready to start typing!

In this module, you take your first steps with C#. You learn how to display output to the console, how to get input from a user, and how to work with text. By the end of this module, you'll have built a small C# program that creates a personalized greeting.
