In this module, you learned how to repeat actions in C# using loops.

You used `for` loops to repeat an action a known number of times, `while` loops to repeat until a condition changes, and `do-while` loops to guarantee that a block of code runs at least once. You also used `break` to exit a loop early and `continue` to skip individual iterations.
