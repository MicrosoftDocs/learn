Learn to install and deploy Windows Server 2025 using supported planning and automation tools, features on demand, and Windows Deployment Services (WDS).

## Scenario

Contoso, Ltd. is a financial services company in Seattle with major offices located throughout the world. Most of its compute environment runs on-premises on Windows Server. This includes virtualized workloads on Windows Server 2016 hosts.

Contoso's IT staff are migrating Contoso on-premises servers to Windows Server 2025. As part of the migration, Contoso plans to expand into additional sites and use virtualization to help expedite bringing a new site online. As a server administrator, you're responsible for deploying Windows Server to help Contoso achieve its business goals.

In this module, you explore the hardware requirements for Windows Server 2025 and the available deployment options. You also compare Server Core with Server with Desktop Experience and explore how Features on Demand improve application compatibility on Server Core.

## Learning objectives

After completing this module, you can:

- Explain the difference between Server Core and Desktop Experience.
- List the hardware requirements for Windows Server 2025.
- Describe the available Windows Server deployment options.
- Describe supported deployment planning and automation tools.
- Enable features on demand.
- Deploy Windows Server using WDS.

## Prerequisites

To get the best learning experience from this module, you should have knowledge and experience of:

- Windows Server.
- Operating system installation procedures.
