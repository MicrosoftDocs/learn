Before using AI-generated content, take time to review it carefully. AI can help create drafts quickly, but it may include inaccuracies, assumptions, or wording that does not fit the employee, workplace, or local context. Use the questions below to evaluate the output before sharing or using it.

- Accuracy: Does it match observation and verified information?
- Accessibility: Can the intended audience find, understand, and use the information?
- Tone: Is it respectful, adult, natural, and person-centered?
- Workplace fit: Does it match the employer's actual process and language?
- Local fit: Verify laws, program names, and local requirements with an authoritative local source. AI may help adjust surface wording, but it should not be the source of local requirements.
- Privacy and security: Is the tool approved, and did you use only the information allowed?
- Bias: Does the output introduce assumptions or lower expectations?
