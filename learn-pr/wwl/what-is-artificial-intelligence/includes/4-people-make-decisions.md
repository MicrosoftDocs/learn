AI can suggest ideas, but it does not make choices for people. Copilot can suggest a checklist. 

The person decides:

- Which steps to follow
- If something is missing
- If a different order works better
- Whether to use the suggestion

AI is a tool. People decide what works best for them.

## Quick safety tip

When using AI, keep personal information private. Do not share:

- Passwords
- A home address
- Private health information
- Personal information such as Social Security Number or bank account information

If someone is unsure about sharing information, they can ask a trusted person for help.
