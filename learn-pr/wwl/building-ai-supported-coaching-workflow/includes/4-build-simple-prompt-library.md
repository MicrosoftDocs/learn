A prompt library can be a document, notebook, spreadsheet, or approved folder. Use a location permitted by your organization. Save reusable wording, not personal details.

| **Field** | **What to record** |
|---|---|
| **Task** | What the prompt helps you do |
| **Prompt** | Reusable wording with brackets for details |
| **Best use** | When this prompt is appropriate |
| **Inputs allowed** | What information may be used and what must be removed |
| **Review checks** | What to verify before using the output |
| **Follow-ups** | Requests that improved the draft |
| **Owner and review date** | Who maintains the prompt and when it should be checked again |

## Example prompt library entry

- **Task:** Rewrite verified workplace instructions.
- **Prompt:** "Rewrite the instructions below for an adult employee. Use familiar words, numbered steps, and one idea per line. Keep every safety and quality point. Add space for photographs. Use only the information provided. Mark anything unclear."
- **Review:** Confirm the complete sequence with the supervisor and employee. Require competent human verification before using any translated safety content.
