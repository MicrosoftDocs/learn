Now it's your turn to use Copilot in Microsoft Fabric Dataflow Gen2.

> [!NOTE]
> Use a workspace assigned to a paid Fabric capacity (F2 or higher) or Power BI Premium capacity (P1 or higher), with Copilot enabled in a supported region. Fabric trials and a Pro or Premium Per User license alone aren't sufficient. Ask your administrator to verify tenant and capacity settings, including cross-geographic processing where required. See [Enable and configure Copilot](/fabric/fundamentals/copilot-enable-fabric).

Launch the exercise and follow the instructions.

The linked exercise uses sample retail store data, rather than the synthetic patient data in the conceptual example. Review each generated Power Query step, set the lakehouse destination, select **Save & run**, and verify the **Store** table. Use a disposable workspace and delete only the resources you create for the exercise.
