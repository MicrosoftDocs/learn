Now it's your turn to analyze data with Apache Spark and Copilot in Microsoft Fabric notebooks.

> [!NOTE]
> Use a workspace assigned to a paid Fabric capacity (F2 or higher) or Power BI Premium capacity (P1 or higher), with Copilot enabled in a supported region. A Pro or Premium Per User license alone isn't sufficient. This exercise uses paid capacity rather than relying on trial availability. Ask your administrator to verify tenant and capacity settings, including cross-geographic processing and storage of notebook conversation history where required. See [Enable and configure Copilot](/fabric/fundamentals/copilot-enable-fabric) and [Copilot tenant settings](/fabric/admin/service-admin-portal-copilot).

Launch the exercise and follow the instructions.

Copilot in notebooks is in preview, so generated code and UI details can vary. Attach the exercise lakehouse as the default, review code before approving execution, and verify the saved **Population** table. For population totals, sum female and male values for the same geography, year, and projection scenario; don't mix projection scenarios or include the source's total row as well. Use only year columns present in the downloaded data. Stop the Spark session and delete only your exercise workspace when you finish.
