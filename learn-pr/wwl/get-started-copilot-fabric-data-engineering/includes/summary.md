In this module, you explore how Copilot in Microsoft Fabric assists with creating, transforming, and analyzing data. You use natural language prompts to generate pipeline activities, create and explain Dataflow Gen2 transformations, and generate notebook code for data preparation and analysis.

Copilot assists you; it doesn't replace your expertise. Check capacity, region, and tenant settings before starting. Review generated code and transformations, respect data handling policies, and validate results against the source data.
