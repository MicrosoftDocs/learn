**Estimated exercise time:** 20 minutes.

In this exercise, you investigate a simulated security incident at Caldova, a robotic pharmacy-delivery service. Its merchant portal and AI support agent appear to operate normally, but two code vulnerabilities allow an attacker to disrupt operations.

## Investigate the Caldova incident

During the simulation, you:

1. **Review the customer experience:** Sign in to the Caldova Pharmacy portal, check orders, and interact with the AI support agent.
2. **Run a controlled security test:** Uncover vulnerabilities that allow an attacker to pause pharmacy operations and access another customer's order.
3. **Verify the business impact:** Identify the authentication, authorization, identity, and resource-ownership controls that fail.
4. **Investigate with Codename MDASH:** Review the vulnerable code in Microsoft Defender and determine how to remediate it.

> [!IMPORTANT]
> This exercise uses fictional customer, order, facility, and application data in simulated Caldova and Microsoft Defender environments. You don't need access to a production environment.
