These prompts can help someone pause and check. They do not prove that a message is real and do not replace help from a trusted person, official source, bank, or service provider.

| **Use** | **Prompt** |
|---|---|
| **Protect information** | Help me rewrite this without names, addresses, account numbers, or other private details: [paste the text]. |
| **Check what is private** | Does this text include private information I should remove? [paste the text]. |
| **Spot warning signs** | What warning signs of a scam or unsafe request are in this message? [paste only the part that does not include private information]. |
| **Make a check plan** | Give me three safe steps to check whether this message is real without replying or using its link or phone number. |
| **Check uncertainty** | What parts of this answer might be wrong or need to be checked? |
| **Find an official source** | What official source should I use to check this information? |
| **Use fewer details** | Help me ask this question without sharing private information: [type the question]. |
| **Get a reminder** | Give me three short rules for using AI safely. |
