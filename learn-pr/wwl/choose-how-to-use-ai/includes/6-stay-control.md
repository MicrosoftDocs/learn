Copilot gives suggestions. A person can use the suggestion, change it, ask for another version, or not use it. A person can also stop using AI at any time.

## Real-world choices

### Planning homework

| **Situation** | **A student has several assignments and does not know where to start.** |
|---|---|
| **Choice** | Use Copilot to suggest an order. |
| **Check** | Compare the plan with the real due dates. |
| **Decision** | Use the plan, change it, or use a paper planner instead. |

### Checking a work schedule

| **Situation** | **A worker needs to know tomorrow's start time.** |
|---|---|
| **Choice** | Check the official schedule or ask a supervisor. |
| **Check** | AI may not have the current schedule. |
| **Decision** | Use the trusted workplace source. |

### Writing a message

| **Situation** | **A person knows what to say but needs help starting a message.** |
|---|---|
| **Choice** | Ask Copilot for a draft. |
| **Check** | Read the message and remove anything that is not right or adjust the language to suit the situation. |
| **Decision** | Send it, change it, or write a new message. |

### Using a familiar support

| **Situation** | **A visual schedule already works well for a morning routine.** |
|---|---|
| **Choice** | Keep using the visual schedule. |
| **Check** | Decide whether AI would add anything useful. |
| **Decision** | Use AI only if it helps. |
