These prompts can help someone decide whether an AI response is useful.

| **Use** | **Prompt** |
|---|---|
| **Compare options** | Give me two ways to organize these tasks: [paste the tasks]. |
| **Ask for a simpler version** | Make this answer shorter and use clear, short words: [paste the answer]. |
| **Check what is missing** | What information is missing from this plan? [paste the plan]. |
| **Choose another format** | Turn this answer into a checklist: [paste the answer]. |
| **Ask what to verify** | What parts of this response should I check with another source? |
| **Prepare to ask a person** | Help me write a question for my teacher, supervisor, or support person about this task: [describe the task]. |
