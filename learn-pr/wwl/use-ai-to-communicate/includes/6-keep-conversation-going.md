After Copilot creates a message, a person can ask for one small change.

## Tell someone a task is finished

| **Prompt** | **Help me write a message to my supervisor. Tell them I finished stocking the shelves.** |
|---|---|
| **Copilot might respond** | Hello, I finished stocking the shelves. Please let me know if there is anything else I can help with. |
| **Follow-up prompt** | Make the message shorter. |
| **Remember** | Read the message before sending it. |

## Ask for help

| **Prompt** | **Help me write a message asking for help with my homework.** |
|---|---|
| **Copilot might respond** | Hello, I need help with my homework. Could someone help me understand the assignment? |
| **Follow-up prompt** | Use simpler words. |
| **Remember** | Make sure the message says what you want to say. |

## Change the tone

| **Prompt** | **Help me write a message thanking someone for helping me at work.** |
|---|---|
| **Copilot might respond** | Thank you for helping me today. I appreciate your support. |
| **Follow-up prompt** | Make the message more friendly. |
| **Remember** | You can change any part of the message. |
