These prompts are ready to copy into Copilot. They can be changed to fit the message.

|---|---|

| **Ask a teacher for help** | Write a short message to my teacher. Say that I need help understanding the homework assignment. |
| **Thank someone** | Help me write a thank-you message for someone who helped me at work today. |
| **Ask a question** | Help me write a message asking a question about my work schedule. |

| **Use clearer words** | Rewrite this message using clear words: [paste the message]. |
| **Friendly message** | Make this message more friendly: [paste the message]. |
| **Ask for support** | Help me write a message asking for help with a task: [paste the task]. |
