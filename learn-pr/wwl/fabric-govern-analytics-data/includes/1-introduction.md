You check the sender before opening an unfamiliar email. You verify a source before citing it in a presentation. Data works the same way. Before someone uses data, they need signals that tell them whether the data is trustworthy, sensitive, or ready for use. Without clear signals, every item looks the same. The cost of guessing wrong is a report built on the wrong data or sensitive information shared with the wrong audience.

**Governance solves both sides of this problem by protecting sensitive data and helping consumers find the right data.** In Microsoft Fabric, the OneLake catalog provides the tools to classify, endorse, document, and monitor data assets across your organization.

This module covers how to apply sensitivity labels, use endorsement to signal trust, document data for discoverability, and monitor governance posture using the OneLake catalog. After completing this module, you can apply governance controls that protect sensitive data and help consumers confidently choose the right assets.
