These prompts are ready to copy into Copilot. They can be changed to fit the task.

| **Use** | **Prompt** |
|---|---|
| **Understand school instructions** | Explain these assignment instructions using short, clear steps: Read pages 10 through 15. Write one paragraph about the main idea. Include two examples from the reading. |
| **Understand work instructions** | Explain these work instructions using short, clear steps: Stock the shelves, check the price labels, and put empty boxes in the recycling area. |
| **Make a school checklist** | Make a checklist for these school tasks: finish my math worksheet, study for Friday's science quiz, email my teacher, and pack my backpack for tomorrow. |
| **Make a work checklist** | Make a checklist for these work tasks: stock the shelves, clean the work area, take out the recycling, and tell my supervisor when I am finished. |
| **Create a study plan** | Make a study plan for my history quiz on Friday. Today is Monday. I can study for 20 minutes each evening. |
| **Write to a teacher** | Write a short message to my teacher. Say that I have a question about the homework and need help understanding question number five. |
| **Write to a supervisor** | Write a short message to my supervisor. Say that I finished stocking the shelves and ask what I should do next. |
| **Organize a job search** | Make a checklist for applying for a grocery store job. Include finding the job posting, completing the application, checking my contact information, and following up. |
| **Plan home responsibilities** | Help me plan these tasks for Saturday morning: do laundry, clean my room, take out the trash, and buy groceries. Put them in a clear order. |
