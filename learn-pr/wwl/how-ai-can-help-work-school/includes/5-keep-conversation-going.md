After Copilot responds, one short follow-up prompt can ask for a small change.

## Organize school tasks

| **Prompt** | **I need to finish my homework, study for a quiz, and email my teacher. Make a checklist for me.** |
|---|---|
| **Copilot might respond** | 1. Finish homework. 2. Study for the quiz. 3. Email the teacher. |
| **Follow-up prompt** | Add times to the checklist. |
| **Remember** | Check the times and change anything that does not work. |

## Understand school instructions

| **Prompt** | **Explain these assignment instructions using short, clear steps: Read pages 10 through 15. Write one paragraph about the main idea. Include two examples from the reading.** |
|---|---|
| **Copilot might respond** | 1. Read pages 10 through 15. 2. Find the main idea.3. Find two examples. 4. Write one paragraph. |
| **Follow-up prompt** | Make the steps even shorter. |
| **Remember** | Compare the response with the original instructions to be sure it is capturing every step and instruction. |

## Plan work tasks

| **Prompt** | **Make a checklist for these work tasks: stock the shelves, clean the work area, and take out the recycling.** |
|---|---|
| **Copilot might respond** | 1. Stock the shelves. 2. Clean the work area. 3. Take out the recycling. |
| **Follow-up prompt** | Put the tasks in the best order. |
| **Remember** | Check workplace instructions before using the list. |

## Write a message to a teacher

| **Prompt** | **Write a short message to my teacher. Say that I need help understanding question number five.** |
|---|---|
| **Copilot might respond** | I have a question about the homework. I need help understanding question number five. |
| **Follow-up prompt** | Make the message more friendly. |
| **Remember** | Read the message before sending it. |

## Organize a job search

| **Prompt** | **Make a checklist for applying for a grocery store job.** |
|---|---|
| **Copilot might respond** | 1. Find the job posting. 2. Fill out the application. 3. Check contact information. 4. Submit the application. |
| **Follow-up prompt** | Make the checklist shorter. |
| **Remember** | A job coach or trusted person can help check the list. |

## Plan home responsibilities

| **Prompt** | **Help me plan these tasks: do laundry, clean my room, take out the trash, and buy groceries.** |
|---|---|
| **Copilot might respond** | 1. Start the laundry. 2. Clean the room. 3. Take out the trash. 4. Buy groceries. |

| **Remember** | Change the plan if it does not fit the day. |
