Copilot can suggest an order for several tasks.

> [!NOTE]
> I need to clean my room, do laundry, and take out the trash. What should I do first? Put the tasks in a clear order.

The person decides if the suggested order works for them.

## Write a short message

Copilot can help someone get started with a message. A student might ask for help writing to a teacher. A worker might ask for help writing to a supervisor. Copilot creates a draft. The person should read and change the message before sending it.
